# Visanam Premium Editorial Direction

## Purpose

Visanam should feel like a carefully illustrated family ritual rather than a children’s-content catalogue or a generic parenting tool. The design places the parent’s real-world concern first, then lets the child enter through an evocative story moment. Every page should make one promise, guide one next action, and leave generous room for the supplied art to carry emotional meaning.

## Design Principles

| Principle | Application in Visanam |
| --- | --- |
| **Space is a signal of care** | Use a deliberate spacing scale, a single visual anchor per viewport, and distinct editorial pauses between ideas. |
| **Typography carries tone** | Preserve the two-font system: Eczar for an expressive, literary voice and Manrope for calm, clear parent guidance. Use fewer size changes and more generous line-height. |
| **One restrained visual system** | Keep deep forest teal, warm parchment, the gold glow, and supplied artwork as the only recurring visual ingredients. Avoid decorative elements that do not clarify a story, action, or value. |
| **The family is the hero** | Frame every claim around a recognisable parent-child moment, a value practised, and one small next action. |
| **Slow, guided discovery** | Replace competing calls to action with one primary action per section, paired with a quieter contextual link where useful. |
| **Story before instruction** | Reveal value-specific previews as compact illustrated story fragments, then connect them to the skill a child practises. |

## Page Architecture

| Page | Role | Primary action |
| --- | --- | --- |
| **Home** | Establish emotional purpose and invite entry into values. The selection box is removed so the hero remains calm. | Explore the values |
| **Values** | Let parents and children browse all eight values through a one-minute story preview, familiar moment, and child-growth outcome. | Create a gentle parent plan |
| **Why Visanam Matters** | Explain why this matters now: the relationship, what happens during a story, what makes the story distinct, and how the family journey continues. | Begin with one value |
| **Parent Journey** | Turn the chosen concern into a manageable, story-led family ritual. | Build the parent plan |

## Evidence Base

The visual system applies premium-design guidance that treats whitespace as a deliberate focus tool, typography as a structural voice, and a tightly controlled graphic language as a sign of quality rather than ornament.[^premium] It also applies web-design principles of emphasis, proximity, readable target sizes, and a repeatable system for layout and interaction.[^principles] The experience-led content structure uses a parent-centred narrative and visual hierarchy to guide attention without making the site feel transactional.[^story]
