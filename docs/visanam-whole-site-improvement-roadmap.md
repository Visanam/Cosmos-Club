# Visanam Whole-Site Improvement Roadmap

## Purpose

This roadmap translates the latest direction into a clearer public experience: **Oru is entered through atmosphere, not an episode catalogue; values are understood through daily life, not story spoilers; parents are shown one calm next action at a time.** It draws only on transferable patterns from leading family and children’s brands, not their visual assets, copy, or product claims.

## The immediate redesign decision

| Area | Decision | Why it serves the visitor |
| --- | --- | --- |
| Story shelf | Remove the public `/story` catalogue, its six teaser cards, its lesson tour, and all `Season 1` episode-gallery entry points. | Fictional episode names were becoming a product layer before a parent understood the family benefit. |
| Navigation | Replace `Stories` with `Enter Oru`; use this as a calm world-introduction route rather than a catalogue. | This preserves child wonder while giving the adult a clear, non-spoiler entry point. |
| Home | Restore the original sunrise-to-night chapter rhythm, but place the existing Oru film as the first full-viewport hero. | The film becomes the first invitation, while the editorial copy explains the parent benefit without competing for attention. |
| Enter Oru | Create a dedicated full-screen video page using a distinct twilight loop and a compact text overlay. | The user asked for the video to own the page; this gives it scale without making the home page feel like a trailer page. |
| Values | Remove every `Story glimpse`, title, preview, and sigil. Retain value, child practice, familiar moment, and why it matters. | A parent can recognise relevance in seconds, without being asked to process fictional plot information. |
| Scenery | Assign one managed visual world per major public route and avoid reusing a scene in a second hero. | Consistent variety makes Oru feel expansive while preserving clean visual recognition across a long visit. |

## Experience architecture

The revised journey should read as **arrival → recognition → practice → reassurance → commitment**. The home page starts with the Oru film, then returns to the preferred sunrise-to-night progression: a morning ritual explains how stories make room for feelings, a dusk chapter clarifies the world without introducing characters as collectibles, a blue-hour section leads to the Values route, and a night return invites the parent journey.

The Enter Oru page becomes an atmospheric pause rather than a commerce surface. Its single full-page film uses a discreet caption, one accessible text description, and two optional actions below the fold: understand the approach or begin with a family moment. The Values page becomes a practical index. It should not mention episodes, sealed plot, or story titles. The Parent Journey remains the principal conversion route because it starts with a family’s real-world need.

## Benchmarks translated into original actions

| Comparable pattern | What current leaders show | Visanam action |
| --- | --- | --- |
| Age and situation routing | Lovevery leads visitors into an age-aware discovery path before it explains developmental support. [1] | Add a concise age-fit line and moment-first entry to the Parent Journey, not a generic product selector. |
| Transparent personalization | Wonderbly presents a simple sequence from choosing a product to making it personal. [2] | Keep the Parent Journey visibly three-part: recognise the moment, choose the value, take one question home. |
| Parent approval beside child delight | Yoto explicitly connects child-led content to parent-facing clarity around age, use, and safety. [3] | Add an explicit trust band on Why Visanam covering age fit, intentional pacing, parent role, and realistic expectations. |
| Everyday context over catalogue browsing | tonies groups discovery around moments in a child’s day. [4] | Remove the public episode shelf and orient discovery around family moments such as change, friendship, frustration, and repair. |
| Concrete learning system | Slumberkins explains a repeatable sequence of book, companion, and affirmation. [5] | Make Visanam’s own method explicit: story, conversation, small practice. |
| Exploration with optional offline extension | Sago Mini pairs imaginative play with printables and physical activities. [6] | Promote existing printable keepsakes as a quiet after-story ritual, rather than adding more plot previews. |
| Trust layer distinct from delight | Khan Academy Kids distinguishes joyful exploration from age, expert, and access guidance. [7] | Keep research, age range, schools, and practical FAQs outside the home hero, but make them easy to locate. |

## Cinematic story-world plan

The live release will use the existing eight-second **Oru passage** in the home hero. Two additional silent, landscape loops have been produced for later placement: **Lantern Walk**, a blue-hour stone-lane drift, and **Starlit Overlook**, a slow night approach to a luminous archway. Their jobs are distinct so they never duplicate one another.

| Asset | Visitor moment | Intended placement | Copy treatment |
| --- | --- | --- | --- |
| Oru passage | Arrival | Home hero | Large two-line emotional promise and one parent CTA over a low-contrast gradient. |
| Lantern Walk | Curiosity | Enter Oru page | Small `Enter Oru` eyebrow, concise invitation, optional sound-free play state. |
| Starlit Overlook | Return | Future post-purchase thank-you or keepsake route | One short reflective question; no conversion interruption. |

All films should remain muted, inline, looped, poster-backed, keyboard safe, and disabled in favour of a still treatment when the visitor requests reduced motion. No video should use a title card, character reveal, or intrusive autoplay audio.

## Page-by-page next improvements

| Route | Priority improvement | Expected impact |
| --- | --- | --- |
| Home | Use the Oru film as the full-viewport opening; retain the original day-to-night reading rhythm below it. | Stronger first impression without obscuring the practical parental reason to continue. |
| Enter Oru | Full-screen film with small, considered overlay and world-context copy below. | Lets the visual work as a brand asset rather than a card inside a content section. |
| Values | Remove plot previews; add concise `children practise`, `familiar moment`, and `why it matters` hierarchy. | Faster scanning and better parent comprehension. |
| Why Visanam | Add a compact trust strip: age suitability, intentional pacing, parent role, and realistic expectation. | Makes claims more credible and reduces the need for dense hero copy. |
| Parent Journey | Add an age-fit note before the first step and preserve the guided ritual layout. | Improves confidence before a parent invests effort in the flow. |
| Pricing | Add a concise `what arrives` timeline and link to the parent ritual. | Reduces ambiguity immediately before checkout. |
| Schools | Use a distinct supplied scenery scene and separate educator proof from sales copy. | Keeps B2B visitors in the same world while making partnership value legible. |
| Keepsakes | Surface a post-story printable ritual rather than new fictional lore. | Extends family use without requiring more on-screen time. |

## Release sequence

The present release implements the removal, video-hero treatment, Values simplification, fresh Enter Oru route, varied scenery assignment, and regression coverage. The next release should test two factual trust-strip variants, refine the age entry, and add route-level client chunking if the production bundle advisory persists. A later content release can introduce the **Starlit Overlook** loop in a post-purchase or keepsake moment, where it supports reflection rather than top-of-funnel conversion.
